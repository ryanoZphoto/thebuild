# Wild West Wall Art

This repository contains a simple static site for Wild West Wall Art. It showcases a gallery of artwork and includes a Netlify-ready form so customers can order metal, acrylic, or canvas prints in preset sizes.

## Development

The site is plain HTML, CSS, and JavaScript. Open `index.html` in a browser to view it locally.

## Deployment

Deploy the contents of this repository to Netlify and enable form submissions to receive orders.
